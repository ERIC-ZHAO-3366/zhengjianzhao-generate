# 证件照排版工具 · 使用说明

纯前端本地工具，所有处理在浏览器内完成，照片不会上传到任何服务器。

## 快速开始

直接双击 `index.html` 用浏览器打开即可（推荐 Chrome / Edge）。无需安装、无需联网、无需任何依赖。

> 若双击打开后某些浏览器限制本地脚本，可改用本地静态服务器：
> ```powershell
> # 在 photo-tool 目录下任选其一
> python -m http.server 8080
> # 然后浏览器访问 http://localhost:8080
> ```

## 文件结构

```
photo-tool/
├── index.html        # 页面结构
├── css/style.css     # 样式
└── js/
    ├── photo.js      # 尺寸预设、裁切、简易换底
    ├── layout.js     # 纸张排版（网格 + 自由拖拽）
    ├── export.js     # 导出图片 / 打印
    └── app.js        # 主控制器，串联界面
```

## 操作流程

### 1. 上传照片
点击「选择照片」或将照片拖入上传区。建议上传构图端正、背景较纯的人像照。

### 2. 背景色（简易换底）
- 保留原图 / 白底 / 蓝底 / 红底
- 「抠图阈值」滑块：阈值越大，被判为背景的像素越多。对纯色背景效果较好；背景复杂或与肤色接近时可能不干净，可手动微调阈值。
- 改动后纸张上已有照片会实时刷新。
- 原理：取图片四角颜色估计背景色，按颜色距离阈值替换，边缘做线性过渡抗锯齿。

### 3. 纸张大小
- 预设：A4(210×297)、A5(148×210)、A6(105×148)、5寸(89×127)、6寸(102×152) mm
- 选「自定义」可手动输入纸张宽高(mm)

### 4. 排版

先在需求列表里设置「尺寸 + 数量」项（尺寸统一在此管理，预设含一寸/小一寸/两寸/小两寸，或选「自定义」填宽高）。点「+ 添加尺寸项」增行，「×」删行。调整「间距 / 页边距」滑块（同时作为照片间距与纸张四周留白）。

**自动排版**：点「按需求自动排版」→ 对每个尺寸按其比例居中裁切原图并换底，用 shelf 贪心装箱算法把所有照片紧凑排到一张纸上。结果显示「已排 N 张」；超出容量会提示放不下的张数。

**排版后可直接调整**（无需切换模式）：
- **拖动**：在照片上按住拖动可移动；选中多张后拖动整组同步移动。单张拖动时若边/中心接近其他照片或纸张边/中线（1.5mm 内）会自动吸附并显示品红虚线参考线
- **添加单张**：点需求列表每行的「＋」往纸张添加 1 张该尺寸照片
- **选择**：单击选中 · Ctrl/Shift 单击多选 · 空白处拖动画框多选 · Esc 取消
- **批量按尺寸选中**：在「批量选择」下拉里选某尺寸（自动列出纸上现有尺寸及数量），点「选中」一键选中该尺寸全部；另有「全选 / 取消选择」
- **对齐**（需选 ≥2）：左 / 水平居中 / 右 / 顶 / 垂直居中 / 底
- **分布**（需选 ≥3）：水平等距 / 垂直等距
- **删除**：选中后按 Delete 删除全部选中；双击或右键单张删除
- **支持一页内混合多尺寸**

点「清空纸张」可重来。

### 5. 导出 / 打印
- **导出 PNG / JPG**：按 300dpi 高分辨率渲染整张纸张并下载
- **打印**：在当前页面内通过隐藏 iframe 完成打印，**不新开窗口**；已通过 `@page` 设定纸张物理尺寸(margin=0)，直接调起浏览器打印对话框

## 尺寸换算参考

| 项目 | 物理尺寸 | 300dpi 像素 |
|------|----------|------------|
| 一寸 | 25×35 mm | 295×413 px |
| 两寸 | 35×49 mm | 413×579 px |
| A4   | 210×297 mm | 2480×3508 px |

## 打印注意事项

1. 打印对话框中「边距」选「无」或「默认」（代码已设 `@page margin:0`）
2. 「缩放」选 100% / 实际尺寸，**不要选「适应纸张」**，否则尺寸会偏
3. 照片纸请按纸张预设选择对应尺寸；用 A4 相纸打印多张一寸照时选 A4 即可
4. 若打印预览发虚，确认浏览器缩放为 100%

## 已知局限

- 换背景为简易颜色阈值法，非专业抠图，对复杂背景、碎发边缘效果有限
- 裁切为固定居中，不提供手动裁剪框（按需求设计）；如构图偏了请自行裁好原图再上传
- 导出 JPG 时背景为纯白，透明区域不会保留
