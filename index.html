1. 上传照片

点击选择 或 拖拽照片到此（可多选）

2. 背景色（简易换底）

阈值越大容错越高。对纯色背景效果较好，复杂背景可能不干净。改动后纸上照片会实时刷新。

3. 边框（打印裁剪用）

边框画在照片外侧，不影响照片本身，打印后可沿边框裁剪。宽度 0 = 无边框。边框不占排版空间，相邻照片边框可紧贴。

4. 纸张大小

5. 排版

上传后此处显示照片列表，每张可独立设置尺寸与数量。

同时作为照片间距与纸张四周留白。

排版后可直接在纸张上手动拖动照片调整位置。

批量选择
已选 0 张
对齐（需选 ≥ 2）
分布（需选 ≥ 3）

单击选中 · Ctrl/Shift 多选 · 空白拖动框选 · Delete 删除 · Esc 取消

6. 导出 / 打印

导出/打印均按 300dpi 高分辨率渲染。处理在本地进行，不会上传数据。
